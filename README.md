# 🧪 Heart Alchemist (Алхимик Сердец)

Welcome to **Heart Alchemist**, a magical journey where feelings are ingredients and love is the ultimate discovery. Created for Valentine's Day, this text-based quest (with a beautiful GUI!) challenges you to collect abstract concepts like **Sincerity**, **Trust**, and **Patience** to brew the perfect elixir.

![The Alchemist](alchemist_portrait.png)

## ✨ Features

- **Double Experience**: Choose between a classic terminal-based adventure or a premium graphical interface.
- **Magical Locations**: Visit the *Alchemist's Workshop*, the *Market of Feelings*, and the *Park of Forgotten Encounters*.
- **Whimsical Characters**: Interact with the Old Sage, the Shy Florist, and the Playful Trickster.
- **Deep Alchemy System**: Discover recipes for *Strong Friendship*, *Deep Devotion*, and the legendary *True Love*.
- **Interactive Challenges**: Solve riddles, unscramble feelings, and prove your patience to earn rare rewards.
- **Rich Visuals**: AI-generated backgrounds and smooth animations bring the world to life.

## 🚀 Getting Started

Ensure you have Python installed, then set up the requirements:

```powershell
pip install Pillow
```

### Run the Game

For the full visual experience:
```powershell
python gui_main.py
```

For the classic text-quest experience:
```powershell
python main.py
```

## 📖 How to Play

1. **Talk** to the characters in each location to gather your reagents.
2. **Solve** the mini-games and puzzles to earn the respect and gifts of the world's inhabitants.
3. **Explore** the connections between the Workshop, Market, and Park.
4. **Mix** your ingredients at the cauldron in your workshop. Check your recipe book to find the right combinations!
